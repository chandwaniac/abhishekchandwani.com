# abhishekchandwani.com

Personal site. Static homepage + Jekyll blog, served by GitHub Pages. No build tooling needed locally.

## Publish a post

Create `_posts/YYYY-MM-DD-slug.md`:

```
---
layout: post
title: "Post title"
---

Markdown body.
```

Push to master. The post appears at `/blog/slug/` and on `/blog/`. When the first post is live, add a `writing` link to the homepage Elsewhere row.
